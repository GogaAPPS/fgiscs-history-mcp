# fgiscs-history-mcp

MCP-сервер над **историей версий** открытых данных ФГИС ЦС — Федеральной государственной
информационной системы ценообразования в строительстве (оператор — ФАУ «Главгосэкспертиза
России», ПП РФ от 23.12.2016 № 1452).

Портал-источник публикует только **последнюю** выгрузку каждого набора. Этот сервер отдаёт
то, чего на портале нет: что изменилось, когда — и что **не** изменилось, хотя выгрузку
опубликовали заново.

История — **198 версий 15 наборов, с 2017 по 2026 год**.

## Зачем

Порталы открытых данных сделаны для скачивания, а не для сравнения. Чтобы узнать, как
значение менялось за шесть лет, нужно найти все прошлые выгрузки, распаковать, починить и
сшить между собой. Здесь эта работа сделана один раз, чтобы её больше не делать.

Конкретный пример, на который сервер отвечает, а портал — нет: две выгрузки Классификатора
строительных ресурсов, `2018-11-22` и `2019-06-17`, **совпадают побайтно**. Портал
опубликовал обновление, в котором не изменилось ничего. Пользователь портала видит только
дату публикации и делает неверный вывод, что данные обновились.

## Установка

Нужен Python 3.10+.

```bash
git clone https://github.com/elysosss/fgiscs-history-mcp
cd fgiscs-history-mcp
pip install -e .
```

Добавьте в конфигурацию MCP-клиента (Claude Desktop, Claude Code, Cursor и другие):

```json
{
  "mcpServers": {
    "fgiscs-history": {
      "command": "python",
      "args": ["/абсолютный/путь/к/fgiscs-history-mcp/server.py"]
    }
  }
}
```

Ни ключа, ни учётной записи, ни обращений в сеть — данные едут вместе с сервером (240 КБ).

## Инструменты

| Инструмент | На что отвечает |
|---|---|
| `list_datasets` | Какие наборы есть и насколько глубокая история по каждому |
| `dataset_versions` | Все версии одного набора с пометками о смене схемы и о переопубликованных, но неизменившихся выгрузках |
| `salary_history` | Среднемесячная оплата труда рабочего 1 разряда по региону, 2020 → 2026 |
| `salary_growth_ranking` | Рейтинг регионов по росту оплаты труда за весь период |

Что теперь может ответить ваш ассистент:

- «Как менялась ставка рабочего 1 разряда в Иркутской области с 2020 года?»
  → +202,5 % (41 621 → 125 911 ₽), со значением по каждой из 8 опубликованных версий.
- «Где оплата труда росла медленнее всего?»
  → Ненецкий АО +44,7 %, Республика Коми +51,1 %, медиана по 74 регионам +88,9 %.
- «Сколько раз менялась схема Классификатора строительных ресурсов?»
  → один раз, 17.11.2022, за 41 версию.

## Данные

| Файл | Что внутри |
|---|---|
| `data/datasets.json` | 15 наборов: число версий, охваченный период, число схем, объём выгрузок |
| `data/versions.jsonl` | 198 версий: дата, дата схемы, размер, sha256, признак дубликата, ссылка на источник |
| `data/oplata-truda.jsonl` | 662 строки — ряды по оплате труда, регион × версия |

У каждого значения есть источник: в записи о версии лежит ссылка на исходный файл на
`fgiscs.minstroyrf.ru`. Ничего не скрейпится — API открытых данных портала публичный и
анонимный, а конвейер загрузки обращается к нему с паузами и отступами.

### Известные оговорки

- В исходных выгрузках названия регионов набраны с латинскими буквами посреди русских слов
  (`Республика Caxa`, `Чукотский автономный oКруг`), пишутся по-разному в разных версиях и
  переименовываются. Поэтому ряды сшиты по **коду субъекта**, а не по названию.
- Нарезка ценовых зон меняется между версиями (91 строка-зона в 2020 году, 117 в 2026),
  поэтому цифра по региону — это **медиана по его зонам**; минимум и максимум сохранены.
- У 11 регионов из 85 нет сквозного ряда: большинство появилось в данных после 2020 года.
