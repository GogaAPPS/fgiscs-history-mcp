# Интерфейсы и эндпоинты MCP ФГИС ЦС

Документ описывает две разные группы интерфейсов:

1. **MCP-инструменты** — функции, которые вызывает агент через MCP-клиент.
2. **API ФГИС ЦС** — публичные GET-эндпоинты портала, к которым MCP обращается для каталога, текущих цен и индексов.

MCP-сервис не предоставляет отдельный REST API для каждой операции. При работе через HTTP все инструменты вызываются через один MCP endpoint. Внутренние маршруты ФГИС ЦС напрямую MCP-клиенту не нужны.

## Адрес MCP-сервиса

| Режим | Адрес/команда | Назначение |
|---|---|---|
| Streamable HTTP | `http://<host>:8000/mcp` | Режим для Docker/Kubernetes и удалённого MCP-клиента. Порт, путь и host настраиваются переменными `FGISCS_MCP_PORT`, `FGISCS_MCP_PATH` и `FGISCS_MCP_HOST`. |
| stdio | запуск `python server.py` | Локальный режим: MCP-клиент запускает процесс и обменивается с ним через stdin/stdout. HTTP-адреса у этого режима нет. |

В Kubernetes сервис доступен внутри кластера по адресу `http://fgiscs-history-mcp.apps.svc.cluster.local:8000/mcp`. Снаружи кластера публичный Ingress не настроен.

## MCP-инструменты

Инструменты сгруппированы по источнику и назначению. Указанные параметры — основные параметры поиска; у большинства поисковых инструментов также есть `limit`.

### Каталог и история

| Инструмент | Входные параметры | Что возвращает |
|---|---|---|
| `list_datasets` | нет | Встроенный список открытых наборов и доступная в репозитории глубина истории версий. |
| `dataset_versions` | `dataset` — идентификатор набора | Даты версий, размеры, SHA-256, изменения схемы и отметки о совпадающем содержимом. |
| `current_open_datasets` | нет | Текущий каталог открытых наборов, полученный с портала при вызове. |
| `current_data_status` | нет | Локальные даты публикации и загрузки, имена файлов, контрольные суммы, количество проиндексированных записей и ссылки на выгрузки. |

### Оплата труда

| Инструмент | Входные параметры | Что возвращает |
|---|---|---|
| `salary_history` | `subject` — название или часть названия региона | Локальный исторический ряд среднемесячной оплаты труда рабочего 1-го разряда; это не текущая ставка в руб./чел.-ч. |
| `salary_growth_ranking` | `limit`, `ascending` | Рейтинг регионов по изменению исторической среднемесячной ставки за доступный период. |
| `search_current_labor_prices` | `query`, `subject`, опционально `period`, `price_zone`, `authority` | Текущие ставки реестра оплаты труда в руб./чел.-ч для выбранных фильтров. |

### Нормы, ресурсы и базисные цены

| Инструмент | Входные параметры | Что возвращает |
|---|---|---|
| `search_construction_resources` | `query`, `kind` (`all`, `materials`, `machines`, `labor`) | Ресурсы локального индекса КСР и извлечённые из ФСНБ: код, наименование, единица, тип и источник. |
| `search_norms` | `query` и/или `norm_code` | Нормы ФСНБ: единица измерения, состав работ, ресурсы с количествами, нормативные ссылки, редакция и источник. |
| `search_base_resource_prices` | `query`, `kind` (`all`, `materials`, `machines`) | Базисные цены из XML ФСБЦ: код, название, единица, редакция, источник и исходные компоненты цены. Компоненты не суммируются MCP в расчётный итог. |
| `search_coefficient_references` | `query` и/или `norm_code` | Нормативные ссылки, прикреплённые к найденной норме. Инструмент не возвращает числовое значение коэффициента и не определяет его применимость. |

### Текущие цены, услуги и индексы

Для онлайн-поиска укажите `subject`. Если у региона несколько ценовых зон, нужно передать `price_zone`. `period` и `authority` можно задать явно; иначе портал выбирает значение по своим справочникам. MCP включает выбранные фильтры, время запроса и источник в ответ.

| Инструмент | Дополнительные параметры | Что возвращает |
|---|---|---|
| `search_current_prices` | `query`, `kind` (`materials` или `machines`) | Текущие опубликованные цены материалов или машин: код, наименование, единица и строки цены. |
| `search_current_transport_prices` | `transport_type`: `rail`, `auto` или `loading_auto`; для `auto` — `road_type`, `vehicle_type`, `vehicle_load_capacity`; может требоваться `authority` | Железнодорожные тарифные интервалы, цены автоперевозки или ставки автопогрузки/разгрузки. Для автоперевозки применяются также фильтры региона, зоны и периода. |
| `search_current_indices` | `query`, `index_type` (сейчас `resource_groups`) | Индексы к группам однородных строительных ресурсов. Это существующий поиск по группам ресурсов. |
| `search_current_building_indices` | `query`, `index_type`: `building_types` или `direct_cost_elements` | Индексы по видам объектов или элементам прямых затрат. Инструмент дополняет `search_current_indices`. |

Если портал вернул пустую выдачу, MCP передаёт пустой результат вместе с фильтрами. HTTP-ошибки и неожиданные схемы ответа обрабатываются как ошибки источника, а не маскируются под отсутствие данных.

## Публичные эндпоинты ФГИС ЦС

Базовый адрес по умолчанию: `https://fgiscs.minstroyrf.ru/api/`. Его можно переопределить через `FGISCS_API_BASE`. Запросы выполняются без Bearer-токена; это публичные GET-маршруты, используемые страницами портала. Состав и схемы ответов могут меняться.

### Каталог открытых данных

| Маршрут относительно `/api/` | Использование |
|---|---|
| `OpenData?page=1&take=200` | Получить список открытых наборов; используется `current_open_datasets` и синхронизатором. |
| `OpenData/GetByNumber/{идентификатор}` | Получить карточку выбранного набора и сведения о файле. |
| `values/GetFileContent/{file_id}` | Скачать файл открытой выгрузки. Используется синхронизатором, а не поиском при каждом вызове MCP. |

После синхронизации КСР и ФСНБ разбираются в локальный SQLite-индекс. Поиск норм, ресурсов и базисных цен выполняется по этой локальной базе; сами эти вызовы не обращаются к API портала.

### Справочники ценовой формы

| Маршрут | Параметры | Использование |
|---|---|---|
| `EstimatedPrice/CountrySubjects` | нет | Справочник субъектов РФ. |
| `EstimatedPrice/PriceZones` | `subjectId` | Ценовые зоны выбранного субъекта. |
| `EstimatedPrice/Periods` | `priceZoneId` | Периоды, доступные для зоны. |
| `EstimatedPrice/Authorities` | `priceZoneId`, `periodId` | Отраслевые организации, публикующие данные для выбранных фильтров. |

### Текущие сметные цены ресурсов

| Маршрут | Использование |
|---|---|
| `EstimatedPrice/BuildingResources/Search` | Подобрать варианты ресурсов по поисковой строке и типу ресурса. |
| `EstimatedPrice/BuildingResources/Search/Materials` | Получить таблицу текущих цен материалов по идентификатору выбранного ресурса и фильтрам. |
| `EstimatedPrice/BuildingResources/Search/Machines` | Получить таблицу текущих цен машин и механизмов. |

Табличные ответы могут содержать группы, внутри которых лежат строки цен. MCP раскрывает вложенные строки до передачи результата инструменту `search_current_prices`.

### Оплата труда

| Маршрут | Параметры | Использование |
|---|---|---|
| `EstimatedPrice/RimWorkerSalaryRegistry` | `periodId`, `priceZoneId`, опционально `authorityId`, `page`, `take` | Текущий публичный реестр ставок рабочего. В строках портал возвращает код разряда/ставки и значение `salary`; MCP фильтрует строки по поисковой фразе. |

### Перевозка и погрузочно-разгрузочные работы

| Маршрут | Использование |
|---|---|
| `EstimatedPrice/Services/TransportationByRail` | Таблица железнодорожных тарифов. Ответ может быть сгруппирован по грузу; MCP разворачивает строки и сохраняет тарифный интервал. |
| `EstimatedPrice/Services/LoadWorksByAuto` | Ставки автомобильной погрузки и разгрузки. |
| `EstimatedPrice/Services/TransportationByAuto/RoadType` | Список типов дорог для выбранных фильтров и организации. |
| `EstimatedPrice/Services/TransportationByAuto/VehicleType` | Список типов автотранспортных средств для выбранного типа дороги. |
| `EstimatedPrice/Services/TransportationByAuto/VehicleLoadCapacity` | Список грузоподъёмности или объёма для выбранных дороги и транспорта. |
| `EstimatedPrice/Services/TransportationByAuto/Data` | Таблица тарифов автомобильной перевозки для фильтров региона, периода, зоны, организации и выбранных параметров автомобиля. |

### Индексы

| Маршрут | Использование |
|---|---|
| `IndicesForResourcesGroups/Search` | Поиск ресурса, для которого портал публикует индекс к группе однородных ресурсов. |
| `IndicesForResourcesGroups/GetTreeViewResourceGroups` | Получить дерево групп для найденного ресурса отдельно для материалов или машин. |
| `IndicesForResourcesGroups/GetTreeViewResourcesInGroup` | Получить значения и сведения об индексе внутри выбранной группы. |
| `IndicesOfChangeEstimatedPrice` | Получить индексы по видам объектов или элементам прямых затрат; режим задаётся параметром `hasDirectCostElementType`. |

В перечисленных таблицах фильтры передаются идентификаторами периода, зоны и, когда применимо, организации. Набор дополнительных полей зависит от типа таблицы.

## Коэффициенты, накладные расходы и сметная прибыль

У ФСНБ есть нормативные ссылки на документы, но текущая SQLite не содержит проверенной таблицы «условие применения → числовое значение → область действия → пункт документа». Поэтому `search_coefficient_references` возвращает ссылки из нормы, а не вычисленные коэффициенты. Публичные маршруты ценовой формы выше не предоставляют универсальную таблицу значений коэффициентов, накладных расходов и сметной прибыли.

## Как обновлять локальные данные

```bash
python sync_data.py             # Скачать актуальные открытые наборы и построить SQLite
python sync_data.py --reindex   # Перестроить SQLite из уже скачанных файлов без запроса к порталу
```

Переиндексация требуется, если в установленной версии MCP появилась новая структура локальных таблиц. Она не обновляет исходные XML/CSV-файлы; для получения свежих публикаций используйте обычную синхронизацию.
