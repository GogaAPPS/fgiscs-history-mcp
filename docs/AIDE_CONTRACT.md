# Контракт AiDe ↔ ФГИС MCP

Этот MCP должен реализовать версию `1.0` контракта из
`AiDe-Back/docs/fgis-mcp-contract.md`. В частности, `search_norms_batch`
принимает идентификатор каждой позиции и возвращает строго JSON-объект с
`contract_version`, `tool`, `status`, `source` и одним результатом на каждый
`query_id`; текстовые ответы и произвольные оболочки недопустимы.
